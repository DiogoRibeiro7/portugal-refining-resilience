# Superseded report artifacts

These documents were produced by the report-writing chain when the evidence bundle was empty.
They correctly reported, at the time, that no quantitative claim could be supported.

They no longer describe this repository. The bundle has since been generated from the four public
sources, the annual analysis has been extended to 1990, and the canonical report states measured
results. **The headline numbers in these files do not match the current report and should not be
read as findings.**

They are kept because they record how the review process ran, and because the final report's
evidence discipline was shaped by the objections raised here.

For current results see [`../report_final.tex`](../report_final.tex), or
[`../report_final.md`](../report_final.md) for a summary.

| File | What it was | Written against |
| --- | --- | --- |
| `data_audit.md` | Audit of the evidence bundle before writing | empty bundle |
| `interpretation_memo.md` | Interpretation of the analysis before prose | empty bundle |
| `report_v1.md` | First report draft | empty bundle |
| `peer_review.md` | Adversarial review of that draft | empty bundle |
