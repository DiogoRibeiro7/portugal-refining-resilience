\section*{Evidence-Limited Final Report}

This final report resolves the peer-review findings by making the evidence status explicit.
It is not a completed empirical assessment of Portugal's 2005--2024 diesel and gasoline
import dependence. It is a bounded report on what the repository's current stored evidence
can and cannot support.

The required empirical report bundle is absent:

\begin{itemize}
  \item \texttt{artifacts/report\_inputs/report\_manifest.json} is missing;
  \item \texttt{artifacts/report\_inputs/} contains no empirical CSV or JSON files;
  \item \texttt{data/metrics/report\_readiness.csv} is missing;
  \item no DGEG trade reconciliation output is available;
  \item no monthly event-timing panel or monthly event-model output is available;
  \item no Eurostat physical-balance panel is available;
  \item no price stationarity diagnostics are available.
\end{itemize}

Consequently, this report does not state measured changes in imports, exports, demand,
refinery output, import dependence, refinery-output-to-demand ratios, structural breaks,
price co-movement, or Portugal--Spain spreads.

\section{Executive Summary}

The repository currently supports a documented institutional timeline:

\begin{itemize}
  \item the Sines hydrocracker entered commercial production in 2013;
  \item Galp announced concentration of core refining at Sines in December 2020;
  \item Matosinhos refining activities ceased during 2021;
  \item 2022 included a documented feedstock shock related to Russian oil products and VGO.
\end{itemize}

The repository does not yet support publication-ready quantitative findings about physical
import dependence or price effects. The missing DGEG reconciliation is especially important:
without it, the trade series cannot be treated as independently cross-checked for a
substantive import-dependence claim. The missing monthly event-timing panel prevents the
report from distinguishing the May 2021 closure period from the March 2022 energy shock
with saved monthly phase summaries and model coefficients.
The missing Eurostat balance panel also prevents a full product-balance cross-check of
production, imports, exports and domestic use.

\section{Research Question and Hypotheses}

The intended research question is whether Portugal's refining-capacity changes altered
dependence on imported finished petroleum products and affected supply resilience or price
transmission.

The intended hypotheses remain testable but untested from the current reporting evidence:

\begin{itemize}
  \item the 2013 Sines hydrocracker may have changed diesel-producing capability and trade
    balances;
  \item the 2021 Matosinhos transition may have changed import dependence and domestic
    refinery-output coverage;
  \item 2022 may represent a distinct supply-system stress episode;
  \item any price-transmission change must be evaluated using pre-tax prices and must not be
    inferred mechanically from refinery closure.
\end{itemize}

\section{Data and Product Definitions}

The intended products are diesel/gasoil and gasoline. The intended annual physical metrics
use thousand tonnes where stored. The intended price analysis uses pre-tax prices as the
primary measure.

These definitions cannot be verified against the final reporting bundle because the bundle
is absent. Available seed files are marked \texttt{seed\_provisional} and are not treated
as publication-ready evidence here.

\section{Methods}

The intended physical-balance metrics are:

\[
\text{NetImports}_{j,t}=M_{j,t}-X_{j,t}
\]

\[
\text{NetImportToDemandRatio}_{j,t}=\frac{M_{j,t}-X_{j,t}}{D_{j,t}}
\]

\[
\text{RefineryOutputToDemandRatio}_{j,t}=\frac{Q^{refinery}_{j,t}}{D_{j,t}}.
\]

Here \(M\) is imports, \(X\) exports, \(D\) domestic demand or sales, and
\(Q^{refinery}\) refinery output for product \(j\) in year \(t\).

The current report does not estimate these metrics because the stored report inputs are
missing. It also does not estimate price co-movement, structural breaks, or event-window
sensitivity.

\section{Physical-Balance Evidence}

No report-ready annual table is available for imports, exports, demand, or refinery output.
Therefore:

\begin{itemize}
  \item no long-run 2005--2024 trade trend is reported;
  \item no post-2013 diesel effect is reported;
  \item no post-2021 Matosinhos effect is reported;
  \item no 2022 decomposition is reported;
  \item no import-dependence or domestic-output-coverage metric is reported.
\end{itemize}

This is a deliberate evidentiary restriction, not an absence of analytical interest.

\section{Price Co-Movement and Portugal--Spain Comparison}

No stored pre-tax price model output or price stationarity diagnostic is available. The
report therefore cannot establish a price effect.

Spain is an intended comparison country, but the current evidence does not support using
Spain as a causal control. Any future causal interpretation would require stored diagnostics
on pre-trends, common shocks, model specification, and confounding from the 2022 European
energy shock.

\section{Robustness and Source Reconciliation}

The data audit and peer review identify missing source reconciliation as a major blocker.
DGEG is configured as the primary Portugal trade cross-check, but no stored DGEG
reconciliation output is available in the report evidence.

Until source reconciliation is stored and audited, no trade-dependence finding is
publication-ready.

\section{Limitations}

The limitations are fundamental:

\begin{itemize}
  \item missing report manifest;
  \item missing report input bundle;
  \item missing readiness file;
  \item seed/provisional data not replaced or cross-validated;
  \item missing DGEG reconciliation;
  \item missing monthly event-timing panel and monthly event-model outputs;
  \item missing Eurostat physical-balance output;
  \item missing structural-break outputs;
  \item missing price-model outputs and stationarity diagnostics;
  \item missing event-window sensitivity results.
\end{itemize}

The report therefore supports documented-event claims only. It does not support descriptive,
statistical-association, or causal claims about the main empirical outcomes.

\section{Conclusions}

Portugal's refining timeline is documented in the repository, but the current stored evidence
is insufficient for a substantive 2005--2024 empirical report on import dependence or price
co-movement.

The next required step is to generate the report input bundle, including:
\begin{itemize}
  \item \texttt{report\_manifest.json};
  \item DGEG reconciliation and monthly event-model outputs;
  \item Eurostat physical-balance metrics and structural-break outputs;
  \item price-model outputs, price stationarity diagnostics and readiness checks.
\end{itemize}
Once those files exist, the report can be revised from an evidence-limited document into a
quantitative analysis.
