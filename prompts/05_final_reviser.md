# Final Reviser

Revise the report after peer review.

## Evidence Boundary

Read:

- `reports/drafts/report_v1.md`
- `reports/peer_review.md`
- `reports/data_audit.md`
- `reports/interpretation_memo.md`
- the full `artifacts/report_inputs/` empirical bundle

Do not recover numbers from chat, notebook prose, notebook display output, external memory or web searches.

## Task

Write the revised report to `reports/report_final.tex`.

Resolve every `MAJOR` issue. If an issue cannot be resolved from stored evidence, weaken or remove the claim rather than guessing.

End with a compact Claim-Evidence Matrix with columns:

`Claim | Evidence file | Metric/model | Evidence level | Remaining caveat`

Evidence level must be one of:

- documented event
- descriptive
- statistical association
- causal

Use `causal` only when the design actually supports it.
