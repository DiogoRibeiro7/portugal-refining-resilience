# Security Policy

## Supported Versions

This repository is research software and tracks the current `main` branch.
Security fixes are applied there first.

## Reporting a Vulnerability

Please do not open a public issue for secrets, credentials, or other sensitive
material. Report privately through GitHub's security advisory flow when
available, or contact the maintainer directly.

When reporting, include:

- affected files or workflows;
- steps to reproduce;
- whether any credentials, private data, or proprietary source files are
  involved;
- suggested mitigation if known.

Raw data dumps, private credentials, API tokens, and local `.env` files should
not be committed.
