# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

Participants are expected to communicate respectfully, focus criticism on the
work, and avoid harassment, abuse, or discriminatory language.

Project maintainers may remove comments, issues, pull requests, or other
contributions that do not meet these expectations.

Instances of unacceptable behavior can be reported to the project maintainer.
Reports will be reviewed and handled in a way that protects the privacy and
safety of the people involved.
